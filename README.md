# HeartCare — Heart Health Dashboard

A web-based heart health dashboard designed to help users explore health assessments, review symptoms, and access heart-health-related information through a simple interface.

## 🌐 Live Demo

**[Visit the HeartCare Website](https://rakshitamahesh.github.io/Heart-attack-detection/)**

## ✨ Features

- **Home Page:** Introduction to the HeartCare website.
- **Health Assessment:** Interface for exploring health-related assessments.
- **Symptoms:** Information about symptoms relevant to heart health.
- **Find a Specialist:** Interface to help users find specialist-related information.
- **Lifestyle and Medical History:** Section for lifestyle and medical-history information.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/RakshitaMahesh/Heart-attack-detection.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

## 🎯 Project Objective

To demonstrate a user-friendly web interface for presenting heart-health information and assessment-related features using standard web technologies.

## ⚠️ Medical Disclaimer

This website is for educational and informational purposes only. It is not a medical diagnostic tool and should not be used to predict or diagnose a heart attack. For medical concerns or emergency symptoms, seek professional medical assistance immediately.
